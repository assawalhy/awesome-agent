# /todo

Add `$ARGUMENTS` as a task to the active epic — per the **awesome-plan** skill.

1. Finish your current in-progress task first — never leave half-done work.
2. Append the task to the epic's TODO.md. If no epic exists, follow the skill's
   placement rules; for a big feature suggest `/epic` instead.
3. Then start the task.
