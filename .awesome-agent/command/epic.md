# /epic

Create a new epic for a substantial feature or goal, then build it — per the
**awesome-plan** skill.

1. Interview the user first: goal, approach, risks, edge cases, and what "done"
   means. Then run the skill's research → plan → approval loop. No
   implementation code until the user replies `go`.
2. Review existing work in the repo for relevant context and conflicts before
   building.
